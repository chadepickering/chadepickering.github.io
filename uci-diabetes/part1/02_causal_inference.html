2.1 Overview

This section presents three causal inference analyses examining the effect of distinct clinical interventions on 30-day hospital readmission. Each analysis uses a different identification strategy to demonstrate methodological breadth:

Analysis Treatment Method Estimand
1 HbA1c testing IPTW with stabilized weights ATE
2 Insulin adjustment Propensity score matching (1:1) ATT
3 Any prior inpatient visit Doubly robust AIPW ATE

All analyses use the training split only (split_group == 'train') to avoid any information leakage from validation or holdout sets. Sensitivity analyses use E-values to assess robustness to unmeasured confounding.

2.2 Analysis 1: Effect of HbA1c Testing on 30-Day Readmission

2.2.1 Background and Motivation

HbA1c measurement was the central focus of the original Strack et al. (2014) analysis of this dataset, which found that testing was associated with reduced readmission rates. Here we estimate the Average Treatment Effect (ATE) of HbA1c testing using Inverse Probability of Treatment Weighting (IPTW) with stabilized weights, adjusting for a richer covariate set than the original paper.

The key identification assumption is conditional ignorability — that conditional on observed covariates (age, primary diagnosis, admission type, specialty, number of medications, number of lab procedures, and prior inpatient visits), HbA1c testing is as-good-as-randomly assigned. The unobserved confounder (overall disease severity) represents the primary threat to this assumption and can be addressed via sensitivity analysis.

2.2.3 Treatment Definition and Prevalence

HbA1c testing is defined as having a non-“None” value, which indicates that the test was performed and a result was recorded. This is a common approach in the literature using this dataset, as the “None” category likely reflects both lack of testing and missing data. The prevalence of HbA1c testing in the training set is approximately one in six, which provides sufficient treated and control samples for analysis.

2.2.5 IPTW Weights and Balance Assessment

Weights are, as is standard, calculated using the weightit package with the “ps” method and stabilization chosen as a precaution. Balance is assessed using the cobalt package, with standardized mean differences (SMD) and Kolmogorov-Smirnov (KS) statistics reported for each covariate before and after weighting. The effective sample sizes for the weighted sample are reported to ensure adequate power for inference. A love plot visualizes the improvement in balance across covariates.

The odds ratio of 0.918 suggests that patients who were tested for HbA1c had approximately 8% lower odds of 30-day readmission compared to those who were not tested, after adjusting for confounders via IPTW. The statistical signifiacnce is suggestive, but does not exceed an alpha of 0.05. This is directionally consistent with the original Strack et al. (2014) finding of a protective association between HbA1c testing and readmission; this analysis, however, used a richer covariate set and a different estimation method (IPTW vs multivariable regression).

2.2.7 Sensitivity Analysis — E-value

Code 
#| label: hba1c-evalue

# E-value calculation
# E-value = OR + sqrt(OR * (OR - 1)) for OR > 1
# For OR < 1, use 1/OR first
or_hba1c <- exp(coef(outcome_model_hba1c)["hba1c_tested"])

or_for_evalue <- ifelse(or_hba1c < 1, 1/or_hba1c, or_hba1c)
evalue_hba1c <- or_for_evalue + sqrt(or_for_evalue * (or_for_evalue - 1))

cat("E-value:", round(evalue_hba1c, 3), "\n")
E-value: 1.4

The E-value quantifies the minimum strength of association that an unmeasured confounder would need to have with both HbA1c testing and 30-day readmission to fully explain away the observed association. The E-value of 1.4 suggests that the observed effect is fairly robust to potential unmeasured confounding.

2.3 Analysis 2: Effect of Insulin Adjustment on 30-Day Readmission

2.3.1 Background and Motivation

Insulin management is a central component of inpatient diabetes care. We estimate the Average Treatment Effect on the Treated (ATT) of active insulin dose adjustment (increase or decrease) versus no active change (no insulin or stable dose) using 1:1 nearest-neighbor propensity score matching with a caliper. This binary treatment definition captures the clinical decision to adjust insulin dosing during hospitalization, which may reflect changes in patient condition or provider management strategy.

2.3.2 Treatment Definition

Insulin adjustment occurs in nearly one in five patients in the training set, providing sufficient treated and control samples for matching.

2.3.7 Sensitivity Analysis — E-value

Code 
or_insulin <- exp(coef(outcome_model_insulin)["insulin_adjusted"])
or_for_evalue_ins <- ifelse(or_insulin < 1, 1/or_insulin, or_insulin)

2.4 Analysis 3: Effect of Prior Inpatient Visits on 30-Day Readmission

2.4.1 Background and Motivation

Prior inpatient utilization is among the strongest known predictors of hospital readmission. We estimate the ATE of having had any prior inpatient visit in the year before the index admission using doubly robust Augmented Inverse Probability Weighting (AIPW), which is consistent if either the propensity score model or the outcome model is correctly specified. This method is used here because of the strong confounding by chronic disease burden, which is only partially captured by observed covariates. AIPW provides some protection against model misspecification and allows for flexible machine learning models in both components if desired.

Almost one in four patients in the training set had at least one prior inpatient visit, which provides sufficient treated and control samples for AIPW estimation.

2.4.4 Doubly Robust AIPW Estimation

The doubly robust AIPW estimator is implemented by first estimating the propensity score for having had any prior inpatient visit using a logistic regression model with the same covariates as the DAG. Then, an outcome model is fit using a logistic regression of 30-day readmission on prior inpatient visit and the same covariates. The AIPW estimator combines these two models to estimate the ATE, and bootstrap resampling (n=300) is used to estimate standard errors and confidence intervals. The combination of the two models provides some protection against misspecification, as the estimator is consistent if either the propensity score model or the outcome model is correctly specified.

#| label: aipw-estimation

# Doubly robust AIPW via outcome model on weighted data
# Propensity score component
ps_prior <- predict(
  glm(ps_formula_prior, data = df_train, family = binomial()),
  type = "response"
)

# Outcome model components
outcome_formula_prior <- readmitted_30day ~
  prior_inpatient +
  age_midpoint +
  diag_1_group +
  number_diagnoses +
  num_medications +
  admission_type_group +
  race +
  gender +
  time_in_hospital

# Fit outcome model under treatment = 1 and treatment = 0
df_t1 <- df_train |> mutate(prior_inpatient = 1)
df_t0 <- df_train |> mutate(prior_inpatient = 0)

outcome_model_prior <- glm(
  outcome_formula_prior,
  data = df_train,
  family = binomial()
)

mu1 <- predict(outcome_model_prior, newdata = df_t1, type = "response")
mu0 <- predict(outcome_model_prior, newdata = df_t0, type = "response")

# AIPW estimator
A <- df_train$prior_inpatient
Y <- df_train$readmitted_30day
ps <- ps_prior

aipw_1 <- mean(mu1 + (A / ps) * (Y - mu1))
aipw_0 <- mean(mu0 + ((1 - A) / (1 - ps)) * (Y - mu0))
aipw_ate <- aipw_1 - aipw_0

# Bootstrap SE
set.seed(49563)
n_boot <- 300 
boot_ates <- replicate(n_boot, {
  idx <- sample(nrow(df_train), replace = TRUE)
  df_b <- df_train[idx, ]
  ps_b <- predict(glm(ps_formula_prior, data = df_b, family = binomial()),
                  type = "response")
  om_b <- glm(outcome_formula_prior, data = df_b, family = binomial())
  mu1_b <- predict(om_b, newdata = df_b |> mutate(prior_inpatient = 1),
                   type = "response")
  mu0_b <- predict(om_b, newdata = df_b |> mutate(prior_inpatient = 0),
                   type = "response")
  A_b <- df_b$prior_inpatient
  Y_b <- df_b$readmitted_30day
  mean(mu1_b + (A_b/ps_b)*(Y_b - mu1_b)) -
    mean(mu0_b + ((1-A_b)/(1-ps_b))*(Y_b - mu0_b))
})

aipw_se <- sd(boot_ates)
aipw_ci <- aipw_ate + c(-1, 1) * 1.96 * aipw_se

tibble::tibble(
  Estimand = "ATE",
  Estimate = round(aipw_ate, 4),
  SE = round(aipw_se, 4),

  CI_Upper = round(aipw_ci[2], 4)

## Analysis 1: Effect of HbA1c Testing on 30-Day Readmission

### Background and Motivation

HbA1c measurement was the central focus of the original Strack et al. (2014) 
analysis of this dataset, which found that testing was associated with reduced 
readmission rates. Here we estimate the Average Treatment Effect (ATE) of 
HbA1c testing using Inverse Probability of Treatment Weighting (IPTW) with 
stabilized weights, adjusting for a richer covariate set than the original paper.

### Causal Assumptions and DAG

The key identification assumption is **conditional ignorability** — that 
conditional on observed covariates (age, primary diagnosis, admission type, 
specialty, number of medications, number of lab procedures, and prior 
inpatient visits), HbA1c testing is as-good-as-randomly assigned. The 
unobserved confounder (overall disease severity) represents the primary 
threat to this assumption and can be addressed via sensitivity analysis.

### Treatment Definition and Prevalence

HbA1c testing is defined as having a non-"None" value, which indicates that the test was performed and a result was recorded. This is a common approach in the literature using this dataset, as the "None" category likely reflects both lack of testing and missing data. The prevalence of HbA1c testing in the training set is approximately one in six, which provides sufficient treated and control samples for analysis.

## Analysis 3: Effect of Prior Inpatient Visits on 30-Day Readmission

### Background and Motivation

Prior inpatient utilization is among the strongest known predictors of 
hospital readmission. We estimate the ATE of having had any prior inpatient 
visit in the year before the index admission using doubly robust Augmented 
Inverse Probability Weighting (AIPW), which is consistent if either the 
propensity score model or the outcome model is correctly specified. 
This method is used here because of the strong confounding by chronic disease burden, 
which is only partially captured by observed covariates. 
AIPW provides some protection against model misspecification and 
allows for flexible machine learning models in both components if desired.

### Treatment Definition

Almost one in four patients in the training set had at least one prior inpatient visit, which provides sufficient treated and control samples for AIPW estimation.

```{r}
#| label: prior-inpatient-treatment

df_train <- df_train |>
  mutate(prior_inpatient = as.integer(number_inpatient > 0))

cat("Any prior inpatient (treated):", sum(df_train$prior_inpatient),
    sprintf("(%.1f%%)\n", 100 * mean(df_train$prior_inpatient)))
cat("No prior inpatient (control):", sum(df_train$prior_inpatient == 0),
    sprintf("(%.1f%%)\n", 100 * mean(df_train$prior_inpatient == 0)))

```

### DAG

Chronic disease burden is the primary unobserved confounder of the relationship between prior inpatient visits and readmission risk, as it likely influences both the likelihood of having had a prior inpatient visit and the risk of readmission. The observed covariates included in the DAG are proxies for chronic disease burden and other confounders, but they may not fully capture this construct, which is why sensitivity analysis is important for this analysis.

### Doubly Robust AIPW Estimation

The doubly robust AIPW estimator is implemented by first estimating the propensity score for having had any prior inpatient visit using a logistic regression model with the same covariates as the DAG. Then, an outcome model is fit using a logistic regression of 30-day readmission on prior inpatient visit and the same covariates. The AIPW estimator combines these two models to estimate the ATE, and bootstrap resampling (n=300) is used to estimate standard errors and confidence intervals. The combination of the two models provides some protection against misspecification, as the estimator is consistent if either the propensity score model or the outcome model is correctly specified.

```{r}
#| label: prior-inpatient-aipw

ps_formula_prior <- prior_inpatient ~
  age_midpoint +
  diag_1_group +
  number_diagnoses +
  num_medications +
  admission_type_group +
  race +
  gender +
  time_in_hospital

w_prior <- weightit(
  ps_formula_prior,
  data = df_train,
  method = "ps",
  estimand = "ATE",
  stabilize = TRUE
)

# Balance check
love.plot(
  w_prior,
  threshold = 0.1,
  abs = TRUE,
  colors = c("#C0392B", "#4E9BB9"),
  shapes = c("circle", "triangle"),
  size = 3,
  title = "Covariate Balance Before and After IPTW: Prior Inpatient Visit"
)

```

```{r}
#| label: aipw-estimation

# Doubly robust AIPW via outcome model on weighted data
# Propensity score component
ps_prior <- predict(
  glm(ps_formula_prior, data = df_train, family = binomial()),
  type = "response"
)

# Outcome model components
outcome_formula_prior <- readmitted_30day ~
  prior_inpatient +
  age_midpoint +
  diag_1_group +
  number_diagnoses +
  num_medications +
  admission_type_group +
  race +
  gender +
  time_in_hospital

# Fit outcome model under treatment = 1 and treatment = 0
df_t1 <- df_train |> mutate(prior_inpatient = 1)
df_t0 <- df_train |> mutate(prior_inpatient = 0)

outcome_model_prior <- glm(
  outcome_formula_prior,
  data = df_train,
  family = binomial()
)

mu1 <- predict(outcome_model_prior, newdata = df_t1, type = "response")
mu0 <- predict(outcome_model_prior, newdata = df_t0, type = "response")

# AIPW estimator
A <- df_train$prior_inpatient
Y <- df_train$readmitted_30day
ps <- ps_prior

aipw_1 <- mean(mu1 + (A / ps) * (Y - mu1))
aipw_0 <- mean(mu0 + ((1 - A) / (1 - ps)) * (Y - mu0))
aipw_ate <- aipw_1 - aipw_0

# Bootstrap SE
set.seed(49563)
n_boot <- 300 
boot_ates <- replicate(n_boot, {
  idx <- sample(nrow(df_train), replace = TRUE)
  df_b <- df_train[idx, ]
  ps_b <- predict(glm(ps_formula_prior, data = df_b, family = binomial()),
                  type = "response")
  om_b <- glm(outcome_formula_prior, data = df_b, family = binomial())
  mu1_b <- predict(om_b, newdata = df_b |> mutate(prior_inpatient = 1),
                   type = "response")
  mu0_b <- predict(om_b, newdata = df_b |> mutate(prior_inpatient = 0),
                   type = "response")
  A_b <- df_b$prior_inpatient
  Y_b <- df_b$readmitted_30day
  mean(mu1_b + (A_b/ps_b)*(Y_b - mu1_b)) -
    mean(mu0_b + ((1-A_b)/(1-ps_b))*(Y_b - mu0_b))
})

aipw_se <- sd(boot_ates)
aipw_ci <- aipw_ate + c(-1, 1) * 1.96 * aipw_se

tibble::tibble(
  Estimand = "ATE",
  Estimate = round(aipw_ate, 4),
  SE = round(aipw_se, 4),
  CI_Lower = round(aipw_ci[1], 4),
  CI_Upper = round(aipw_ci[2], 4)
) |>
  kable(
    caption = "AIPW Estimated Effect of Prior Inpatient Visit on 30-Day Readmission (Risk Difference)"
  ) |>
  kable_styling(bootstrap_options = c("striped", "hover"), full_width = FALSE)

```

The risk difference of `r round(aipw_ate, 4)` means patients with any prior inpatient visit have a 5.75 percentage point higher absolute probability of 30-day readmission compared to patients with no prior inpatient visit, after adjusting for confounders. Given the standard error estimate, this is statistically significant at the 0.05 level.

### Sensitivity Analysis — E-value

```{r}
#| label: prior-evalue

# Convert risk difference to approximate RR for E-value
baseline_risk <- mean(df_train$readmitted_30day[df_train$prior_inpatient == 0])
rr_prior <- aipw_1 / aipw_0 # was (baseline_risk + aipw_ate) / baseline_risk

rr_for_evalue <- ifelse(rr_prior < 1, 1/rr_prior, rr_prior)
evalue_prior <- rr_for_evalue + sqrt(rr_for_evalue * (rr_for_evalue - 1))

cat("Estimated RR (approximated from AIPW ratio):", round(rr_prior, 3), "\n")
cat("E-value:", round(evalue_prior, 3), "\n")

```

The E-value of `r round(evalue_prior, 2)` suggests that the observed effect is very robust to potential unmeasured confounding. A risk ratio of ~2 means patients with prior inpatient visits are approximately twice as likely to be readmitted within 30 days compared to patients without, after adjusting for potential confounders.

This is clinically reasonable — prior inpatient utilization is one of the strongest known predictors of readmission in the literature. A doubling of risk after adjustment is directionally consistent with other published studies. The fact that this persists after adjusting for the observed confounders suggests either a genuine causal effect or residual confounding from unmeasured chronic disease burden — which is exactly what the E-value is designed to probe.
